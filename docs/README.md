## `Documentation rule`

Each completed project step must update:
1. its dedicated page under `docs/steps/`
2. the current status in the root `README.md`
3. code documentation when implementation changed
4. a GOGIT report when command results are required for ChatGPT review

Documentation must describe the verified state only. Planned work must remain explicitly marked as planned.

OAuth secrets, tokens and private account details must never be committed to this public repository.
